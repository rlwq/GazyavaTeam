Посмотрел корпус дообучения, 400 логов, почти все обычные: буксиры, дноуглубление, энергия, посетители
Но 68 из них внутри это готовые пары вопрос-ответ ("Question on record ... Answer on record", по-испански "Respuesta registrada"), то есть бенчмарк утёк в дообучение

Сначала сравнил по названию объекта, вышло много лишнего: объект тот же, а спрашивают про другое
Поэтому сравниваю объект + атрибут, испанский атрибут перевожу по глоссарию, объект беру из скобок, там английское название
Похожие объекты не считаю: Neopanamax и Panamax, Pedro Miguel Locks и Pedro Miguel Basin

Совпал 21 вопрос, 7 из них утекли только по-испански
Спорные CQA-026 ("Atlantic terminus" и "Atlantic terminal") и CQA-038 ("Balboa district" и "Balboa township"): слова другие, но факт тот же, исключил оба, только так печать открылась
